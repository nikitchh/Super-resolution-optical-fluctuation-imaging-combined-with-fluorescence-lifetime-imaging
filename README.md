# Super-resolution-optical-fluctuation-imaging-combined-with-fluorescence-lifetime-imaging

This code implements the SOFI algorithm on a dataset obtained from a model experiment. The dataset contains approximately 486 thousand frames, which are sliced videos shot on a model experiment. The description of the experimental setup is given in the text of the article [Super-resolution optical fluctuation imaging combined with fluorescence lifetime imaging microscope: Proof of concept experiment].

The program Sofi_analysis.py calculates the cumulants of intensities for the given data array and builds an image of blinking emitters with improved resolution. Two types of emitters were used in the model experiment, which corresponded to a short and long attenuation time after excitation. According to these statistics, it was assumed that each emitter has an initial value of the theta parameter: for “fast” emitters value is +1, and for the “slow” equals -1. The program calculates this parameter using cumulants values. Parameter maps corresponding to the six orders of cumulants are constructed according to the theoretical introduction from the mentioned article.

In order to run the program, you must first download the dataset from zenodo repository and unzip the archives []. It is necessary to unpack all the archives into one folder, without changing the names of the files in the archives. Before launching, you need to make sure that the numpy, scipy, matplotlib, and opencv-python libraries are installed for the Python on your computer. Also in the code Sofi_analysis.py you must specify the path to the folder with the frames in the “folder” variable. After that, you can run the program through any Python IDE or with the command “python Sofi_analysis.py” using command line. In normal program execution, it may be necessary to close the matplotlib graph window in order for the program to continue. 

After the first start, the values for the first and second time channels F1, F2 and the frame indices for the signal double and single flashes are stored in the cache. This is done for the convenience of working with graphs when running the program multiple times. In order to recalculate the cache from the very beginning, before starting, set the values to “True" for the variables “REBUILD_STARTS_CACHE” and “REBUILD_FRAME_CACHE”. After the first launch, in order not to do unnecessary long calculations for the same dataset, but simply build images and graphs, you can replace both values with “False".

The value of parameter “SOFI_SERIES_MODE = 40” indicates the SOFI mode. For a value of 40, the program will assume that there are 40 excitation cycles in one SOFI frame (as in the article), but with a value of 20, the program will split the original SOFI blocks into two 20 excitation cycles each. This way, you can double the number of SOFI frames.

During execution, the program outputs maps of the theta parameter for each cumulant order, an image of the emitters constructed using cumulants, and a graph of the cross section of parameter map. The program also outputs to the console the values of the theta parameter corresponding to the midpoints of the blinking dots.  The calculations for the article were done on Python version 3.13.
